# Messaging

Poppet can talk to you through a Discord or Slack bot. Each bot replies only to its configured owner, in threads in your server or workspace. Scheduled results and failure notices can be posted to a home channel.

- [Discord](discord.md): create the bot, connect it, and chat in threads.
- [Slack](slack.md): connect a Socket Mode app and chat in threads.

Terminal chat works without messaging. Messaging needs the [worker](../worker.md) running.
