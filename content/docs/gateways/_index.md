# Messaging

Poppet can talk to you through a Discord, Slack, or Telegram bot. Each bot replies only to its configured owner. Discord and Slack use threads; Telegram supports private chats, groups, and forum topics. Scheduled results and failure notices can be posted to a home channel.

- [Discord](discord.md): create the bot, connect it, and chat in threads.
- [Slack](slack.md): connect a Socket Mode app and chat in threads.
- [Telegram](telegram.md): connect a bot for a private chat, group, or forum.

Terminal chat works without messaging. Messaging needs the [worker](../worker.md) running.
