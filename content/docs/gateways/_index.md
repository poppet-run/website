# Messaging

Poppet can talk to you through a Discord bot. The bot replies only to its owner, in threads in your server. Scheduled results can be posted to a home channel.

- [Discord](discord.md): create the bot, connect it, and chat in threads.

Terminal chat works without messaging. Messaging needs the [worker](../worker.md) running.
