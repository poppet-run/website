# Poppet documentation

Poppet runs on your computer and uses a model provider you choose. Start with [getting started](getting-started.md) to send your first message, then pick a guide for what you want to do next.

## Start here

- [Getting started](getting-started.md): install Poppet, connect a provider, and send a message.
- [Providers](providers/_index.md): compare ChatGPT, OpenRouter, and OpenCode Go, and connect one.

## Use Poppet

- [Chat](chat.md): hold a conversation, return to it later, and search earlier answers.
- [Web chat](web-chat.md): chat from a browser on your computer or phone.
- [Memory](memory.md): tell Poppet about yourself, shape how it writes, and ask it to remember facts.
- [Skills](skills.md): write a procedure once and choose it for a chat or task.
- [Run commands](commands.md): understand how Poppet runs commands on your computer and when it asks you first.

## Schedule work

- [Scheduled tasks](tasks.md): run a prompt later or on a schedule, then edit, pause, or skip it.
- [Worker](worker.md): keep Poppet running in the background so tasks and messaging work.

## Connect services

- [Messaging](gateways/_index.md): chat with Poppet in Discord or Slack, and post scheduled results to a channel.
- [Read and search the web](web.md): let Poppet read pages you link, or turn on web search with Brave or Kagi.
- [MCP tools](mcp.md): give Poppet tools from other apps and services you trust.

## Reference

- [Configuration](configuration.md): change settings in `config.json` and manage API keys.
- [Command line](cli.md): look up every command and option.
- [Storage](storage.md): find your data, back it up, and see what Poppet keeps.
- [Doctor](doctor.md): check your setup for problems without changing anything.
- [Troubleshooting](troubleshooting.md): fix common problems with providers, tasks, and messaging.
