# Poppet documentation

Poppet runs on your computer and uses a model provider you choose. Start with [getting started](getting-started.md) to send your first message, then pick a guide below for what you want to do next.

## Start here

- [Getting started](getting-started.md): install Poppet, connect a provider, and send a message.
- [Providers](providers/_index.md): compare ChatGPT, OpenRouter, and OpenCode Go, and connect one.

## Use Poppet

- [Chat](chat.md): hold a conversation, resume a session, and find earlier answers.
- [Memory](memory.md): keep your profile, Poppet's personality, and facts you ask it to save.
- [Skills](skills.md): write a reusable procedure and choose it for a chat or task.
- [Run commands](commands.md): let Poppet run shell commands, with a review before each one.

## Schedule work

- [Scheduled tasks](tasks.md): schedule a prompt, then edit, pause, skip, or snooze it.
- [Worker](worker.md): keep scheduling and messaging running, in a terminal or at macOS login.

## Connect services

- [Messaging](gateways/_index.md): chat with Poppet in Discord threads, and send scheduled results to a channel.
- [Read and search the web](web.md): read public pages, or turn on web search with Brave or Kagi.
- [Browser automation](browser.md): open and read websites, and fill in forms when you ask.
- [MCP tools](mcp.md): choose which tools Poppet can use from trusted MCP servers.

## Reference

- [Configuration](configuration.md): save settings in `config.json`, and manage API keys and optional tools.
- [Command line](cli.md): look up commands and options.
- [Storage](storage.md): find your data, check the database, and understand interrupted work.
- [Troubleshooting](troubleshooting.md): check configuration, provider access, the worker, Discord, and optional tools.
