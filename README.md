# Poppet website

The website and user documentation for [Poppet](https://poppet.run), a personal AI
assistant that runs on your computer.

Visit the [documentation](https://poppet.run/docs/) to get started, or see the
[Poppet repository](https://github.com/poppet-run/poppet) for the app source.

The Open Graph image is `static/images/poppet-social.png`. Its source is
`assets/images/poppet-social.svg`: the still pixel mascot
(`static/images/poppet-pixel-transparent.png`) embedded at 22 px per art pixel with
`image-rendering: pixelated`, above the Avenir Next Heavy wordmark and Avenir Next
Bold domain lettering converted to outlines. Export the SVG at 1254 × 1254 pixels
in a browser when updating the PNG, so the pixels stay sharp.
